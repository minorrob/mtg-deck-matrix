About the Commander

Krenko, Mob Boss

  • · 3/3 · Legendary Creature — Goblin Warrior
  • No keyword abilities recorded
  • {T}: Create X 1/1 red Goblin creature tokens, where X is the number of Goblins you control.

Establish a Goblin board before tapping Krenko. More Goblins increase the token count each activation.

Strategy & how to play

Goblin go-wide. Krenko doubles the board every activation, then a damage payoff converts bodies into a win without needing combat to connect. The fastest clock in the pod.

Engine

Krenko's tap ability with Thousand-Year Elixir and Thornbite Staff to untap him, so the token count squares instead of doubling. Purphoros turns every token that enters into 2 damage per opponent.
