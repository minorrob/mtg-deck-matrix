# Bronze & Basalt

A dwarven hall: warm basalt, bronze-bound edges, the same sapphire, gold and crimson; vellum by day.

The same sapphire, gold, crimson and emerald on warm stone instead of cold. Use it when someone wants the table to feel like a hall rather than a night sky. Only the neutrals change, so every hue keeps its job.

A skin of the CrankMagic r4 system: this folder sets colors only. Type, shape, motion and every component are the governing system's (../../readme.md).
