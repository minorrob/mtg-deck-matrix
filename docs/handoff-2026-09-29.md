## How the work was done (the loop)

1. **Build.** Write a failing check first, and a break runner in the scratchpad (a deliberate break per change; every break must be caught).
2. **Screenshots** via SendUserFile.
3. **Bump pins:**
   - `node tools/bump-pins.mjs <files>`
   - then `crankmagic-sw.js`
   - then `crankmagic-app.js`
   - then `node tests/asset-versions.mjs --update`
4. **Register** a new suite in the README and bump its count.
5. **Commit:** `git add -A && node tools/data-inventory.mjs`, then commit with the trailers.
6. **Push and open a draft PR.**
7. **The local gate:** `sh tools/local-ci.sh <sha> 2`, about 30–45 minutes, because Actions cannot run.
8. **Merge:** post the PASS block as a comment, mark the PR ready, and merge with `merge_method: merge` and the full head SHA, under AGENTS.md "Merging to main".
9. **Restart the branch:**

   ```
   git fetch origin main && git checkout -B claude/magical-davinci-spajci origin/main && git push -f
   ```

**Releases.** Workers Builds deploys `crankmagic-staging` on a push to `release/cloud-staging`, and `crankmagic` on a push to `release/pages`.

1. Build from a clean worktree of the main commit, since the working tree's builder may be newer than main:

   ```
   node tools/release-pages.mjs --ref <sha> --profile cloud-staging --out <dir>
   ```

2. Walk it:

   ```
   node tools/serve-folder.mjs <dir> <port>
   UAT_BASE=http://crankmagic.localhost:<port> UAT_STATIC=1 UAT_LIVE_NETWORK=1 node tests/uat/release-acceptance.mjs
   WRANGLER=<wrangler.js> node tests/uat/play-e2e.mjs      # staging
   ```

3. Check D1 migrations:

   ```
   CLOUDFLARE_API_TOKEN=injected-by-proxy npx -y wrangler@4.139.0 d1 migrations list <db> --remote
   ```

4. Commit and push the release:

   ```
   node tools/release-pages.mjs --ref <sha> [--profile cloud-staging] --commit
   git push origin release/<branch>
   ```

5. Confirm the new deployment through the Cloudflare API: `accounts/<id>/workers/scripts/<worker>/deployments`.

Staging first, always. Production only on Rob's go, every time.
