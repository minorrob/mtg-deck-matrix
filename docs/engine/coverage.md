# Engine coverage

Generated by `node game/tools/engine-coverage.mjs --write`.

**What this counts.** Not how many cards have definitions — that is zero until phase 3, which is
true and useless. It counts how many cards the engine already has *every rule for*: every
effect, trigger, static, replacement and keyword the card uses is one the engine implements.
A keyword counts only when it does something — declaring `Flying` is what lets a card script
say it, and `keywords/combat.mjs` is what makes a flier unblockable by the ground.
