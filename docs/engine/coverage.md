# Engine coverage

Generated by `node game/tools/engine-coverage.mjs --write`.

**What this counts.** Two things. *Defined* is how many cards have a definition in
`game/engine/cards` that the engine can play, each with its scenarios (1055 definitions in all):
the cards a table could seat today. *Every rule* is how many the engine already has every rule
for: every effect, trigger, static, replacement and keyword the card uses is one the engine
implements, so writing its definition is all that is left. A keyword counts only when it does
something — declaring `Flying` is what lets a card script say it, and `keywords/combat.mjs` is
what makes a flier unblockable by the ground.
