## Approved activated / route / cost slice

The following implementation is bounded to priority casts and ordinary modal activations. It preserves the existing
cast-client fields, adds activated schemas and reads effective abilities through native `offerScript`/`offerSpecs`.
`engine-action-stages` and `room-action-stages` provide the actual RED-to-GREEN evidence. No actions, asking, payment,
house-pilot, Battle or verifier module is edited. W5 received the exact funded Scepter reproduction and owns that debt.

## Separate committed-question design

Root approved this design only as a later slice after the activated checkpoint is clean and published. The real native
awaiting/controller question remains in place. A private sidecar stores its identity/signature and selected references;
it never stores an engine snapshot to restore, writes back an old question, or invokes a priority action directly.
Saved stack script/LKI supplies mode facts even after source departure. Native kind/stack or operation identity and
current variants must revalidate on view, answer, reload and actor/target departure.

Back edits only private selections. Closing the child reveals the unchanged still-live mandatory question, returns no
priority, and retains required-choice guidance. A native optional decline must execute the original handler, including
remaining effects. Final confirmation invokes that original handler once and uses W5's actual play/payment continuation.
Copies keep their selected modes. Native random mode rolls remain native RNG commitments; Back cannot cross a roll or
other committed boundary. Unsupported free-spree casts stay unavailable until their real payment implementation exists.
The original activated checkpoint included no committed-question production change. The separate approved slice now
implements the bounded live-question refinement in COMMITTED-MODAL-CONTRACT.md: actual controller68/native60/room201,
generation-room45/epoch30 and54 caught probes with the original eight-reader baseline retained. Original pending and
committed engine facts remain intact during child steps; current native generations reoffer after external changes,
and server-stamped raw private requests retain exact receipt identity across replay/expiry/JSON. Counted-target steps
and unavailable additional-cost casts stay native/unsupported here. Shared UI consumption and full route acceptance
are not claimed by these bounded fixtures.
