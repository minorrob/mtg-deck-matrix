## Gotchas learned this session (beyond §2 of the plan)

- `tools/screens.mjs` waits for a per-route landmark (`.cm-deck-hero`, `.cm-pull`, the roster
  table) because the deck overview awaits Scryfall, which hangs in the sandbox for ~a minute.
- Bumping `crankmagic-sw.js?v=` edits `crankmagic-app.js` (the registration), so `crankmagic-app.js`
  must be bumped too or `asset-versions` refuses `--update`. `bump.py` lived in the scratchpad;
  it is a 15-line loop over index.html, crankmagic.html, crankmagic-sw.js, crankmagic-app.js.
- `mcp__github__actions_list` returns 80 KB; use `actions_get` with `get_workflow_run` and the
  run id from the first list call instead. Merging through the API works: `update_pull_request
  draft:false`, then `merge_pull_request` squash. After a squash, reset the working branch to
  `origin/main` (force-with-lease) or the next PR carries the old diff.
- `Number(null)` is 0: guard unknown prices before arithmetic (see `num()` in the rules module).
- `.v-button` labels are `white-space:nowrap` now; a long label on a 320px phone is worth a look.
- The geometry pass counts every `.v-button` in `.cm-actions|.cm-toolbar|.cm-batch-bar|.cm-shop-bar`;
  a new row that mixes sizes fails it.
