# Persona portraits (placeholders)

Four small SVG busts, one per persona in `game/engine/pilots/roster.mjs`, drawn for 96 px. They are placeholders: Rob
decides whether they are replaced (`docs/ai-players/PLAN-2026-10-26.html`, section 12). A replacement keeps the file name
and a 1:1 shape; the roster names each by path, and `tests/ai-personas.mjs` refuses a persona whose file is missing.
