# Rob's playmats

Rob Minor's own artwork, published as mats for Play (2026-09-29: "They're all mine, publish them, excluding the
initial 7"). The seven older mats in `game/ui/assets/playmats` are not these and are not published.

Each came from Rob's Playmats folder as a PNG of about 1830–2620 px wide. It is kept here downscaled, never cropped:

- `<id>.webp`, at most 1920 px wide (WebP, quality 80), for the board and the Choose mat preview;
- `<id>-thumb.webp`, 320 px wide (quality 76), for the picker.

The ids are `ART_MATS` in `game/room/table.mjs`, the names are in `crankmagic-table.js`, and `crankmagic-mats.css`
draws them. That stylesheet is Play only, so a release without Play ships none of these pictures
(`tools/release-pages.mjs`).
