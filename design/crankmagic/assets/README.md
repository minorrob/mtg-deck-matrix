# Approved brand assets

The user selected the wand variant: a gear with integrated mana symbols, a long wand behind a fan of blue, black and red cards, and the five-color emblem on the front card. The logo was generated during this design review. With the user's explicit approval, local image processing removed the painted backdrop while preserving the black card and slightly brightened the outside contour.

`crankmagic-logo-wand-v3.png` is the transparent master. The 256px PNG is the display derivative; the equivalent lossless WebP is embedded in the mockup. These files retain the approved artwork, not a newly generated substitute. Magic imagery and symbols remain the property of their respective rights holders.

Satoshi 400/500/700 is embedded from [Fontshare](https://www.fontshare.com/fonts/satoshi); the downloaded source CSS is included. The blue wordmark uses an embedded Oxanium 700 subset containing “CrankMagic,” obtained from [Google Fonts](https://fonts.google.com/specimen/Oxanium). Its source CSS and SIL Open Font License are included. The interface remains Satoshi and the app remains dark regardless of OS appearance.

The decorative aether is generated by `../src/crankmagic-brand.js` and styled by its CSS. It wraps the subline in diffuse mist, branches progressively into tendrils, adds no header height and supports pause and reduced motion. It is independent of the blue/green progress orbs in Play Lab.

Commander image provenance is in `../art/commander-sources.json`; background card-art provenance is in `../art/base-sources.json`. Mana display SVGs live in the repository's `assets/mana/` and have their provenance in `docs/glossary.md`.
